    Simulation State Rules:
    • Start: Valid when IDLE; pulls top-priority job from queue.
    • Pause: Freezes rendering loop during active printing.
    • Resume: Unfreezes engine and continues from current page.
    • Simulate Error: Aborts active job into FAILED and flags ERROR.
    • Reset: Returns ERROR or OFFLINE state back to IDLE.
